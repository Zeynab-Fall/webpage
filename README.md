 # Webpage for New Zealand Photo Collection 

This is a digital library containing 50 photos taken during my time in New Zealand. Each photo includes metadata such as title, date, location, photographer, subject, cultural significance, and keywords. The photos are displayed with individual pages for each item. 

## Files on my GitHub page:

- images
- index.html
- style.css 
- collection.json
- script.js
- item-template.html 
- item.js
